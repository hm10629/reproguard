## 2. 三者为何入选

| 项目 | 形态特点 | 主要检验的规则方向 |
| --- | --- | --- |
| U-Net (jaxony/unet-pytorch) | Python，仓库仅 5 个文件，**无训练脚本、无数据集处理、无 `requirements.txt`** | 数据预处理与划分、入口命令、结果生成、论文与代码名称对应 |
| YOLOv3 (pjreddie/darknet) | C / CUDA，含 `Makefile` 与 `cfg/` 配置，需编译 | 关键超参数、硬件与环境、入口命令、权重与数据集来源 |
| BERT (google-research/bert) | Python，**代码完整**（含 `requirements.txt` 与多个入口脚本），但依赖 TensorFlow 1.x | 依赖及版本、硬件与环境、预训练权重来源、复现范围 |

三者构成一组对照：**代码不完整**、**非 Python 编译型**、**代码完整但环境已过时**。这比单独一个项目更能暴露规则是否只在某一种项目形态下有效。
