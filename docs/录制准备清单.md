## 录制前 10 分钟检查

1. 浏览器只保留 GitHub PR、Action 运行和本地报告窗口；关闭通知及无关标签页。
2. 页面缩放到 110%-125%，关键行号、`needs_review` 和 Action Summary 至少停留 3 秒。
3. 检查画面中没有 API Key、部署私钥、个人邮箱、本机用户名、临时目录或第三方论文原件。
4. 使用 `reports/pytorch-unet-pr-141.md` 时标注“真实历史 PR 回放”；使用 `data/examples/incomplete-ml-project` 时标注“自造固定样例”。
5. 录制前运行一次 `python -m unittest discover -s tests -v`；若不再重跑，旁白只引用已记录的 154/154 结果。
6. 预先打开本地文件，避免视频中搜索路径或暴露本机目录结构。

## 失败降级

- GitHub 页面加载慢：使用已保存的 Action 截图和报告截图，旁白明确这是同一次真实验收的静态证据。
- 模型页面不便展示：使用 `reports/ai-real-call.md`，说明模型调用已完成且经人工逐项核对。
- 线上仓库已经公开：可以演示公开仓库、PR 和 Action，但不出现 `hm10629/reproguard@v1` 已可被第三方调用的表述。
- 录屏超时：优先保留真实 PR、三条风险、人工评测前后对照和 Action 四项输出；网页模式和本地模型降级路径可删减。
