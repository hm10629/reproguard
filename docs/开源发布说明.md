## 与外部开源资源的边界

- 本项目属**自建项目**，不是对某个现有开源项目的二次开发。
- 使用 pypdf 仅作 PDF 文本解析，未修改其源码。
- 未复制任何第三方项目的模板或代码。

## 模型模式的边界

- 模型结果只作辅助，不改变规则判定，也不作为证据。
- 模型只能引用工具给出的来源编号，未知编号被丢弃。
- 不向外部发送论文、代码或密钥。

## 本机环境限制（不影响仓库内容）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `git status` 报 `fatal: detected dubious ownership` | 仓库目录属主为 `CodexSandboxOffline`，与本机当前 shell 登录用户不同 | 用 `git -c safe.directory=<仓库绝对路径> <命令>` 单次生效；**不要**修改全局 Git 配置 |

该项目目录由协作工具在隔离账户下创建，因此属主与日常登录用户不一致。这是**本机权限问题**，不是仓库内容问题。正式发布时由人在本机处理，**不由 AI 代改全局配置**。
